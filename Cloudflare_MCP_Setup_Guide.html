คู่มือเชื่อมต่อ MCP ผ่าน Cloudflare Tunnels

ระบบเชื่อมต่อ Claude Desktop (Local) กับเซิร์ฟเวอร์ Spectra QA (Remote) อย่างปลอดภัย 100%

# สถาปัตยกรรมระบบ (Architecture)

การใช้ Cloudflare Tunnels (SSE) ร่วมกับ Stdio Proxy จะช่วยสร้างท่อเข้ารหัสจากเครื่องเซิร์ฟเวอร์ ออกสู่อินเทอร์เน็ตโดย ไม่ต้อง Forward Port หรือมี Public IP เลย

Claude (Machine B)
→
Proxy (mcp-proxy.js)

→
Cloudflare Tunnel

→
Spectra QA (Machine A - Port 3000)

1 ตั้งค่าฝั่งเซิร์ฟเวอร์ (Machine A)

เครื่องที่รันระบบ Spectra QA (Host) จะต้องปล่อย API แบบ SSE (Server-Sent Events) รันไว้ที่พอร์ตภายใน เช่น 3000

การเปิด Cloudflare Tunnel

ติดตั้งโปรแกรม cloudflared ในเครื่อง Machine A และรันคำสั่ง:

# สำหรับทดสอบ (Quick Tunnel)
cloudflared tunnel --url http://localhost:3000

# สำหรับใช้งานจริง (Persistent Tunnel)
cloudflared login
cloudflared tunnel create spectra-qa-mcp
cloudflared tunnel route dns spectra-qa-mcp mcp.yourdomain.com
cloudflared tunnel run spectra-qa-mcp

หลังจากรัน คุณจะได้ URL มาใช้งาน เช่น https://spectra-qa-test.trycloudflare.com

2 ตั้งค่าฝั่งเครื่องส่วนตัว (Machine B)

เครื่องที่ลง Claude Desktop ไว้ จะต้องใช้ "Proxy Script" เพื่อแปลงการคุยแบบ Stdio ให้เป็น SSE เพื่อส่งขึ้น Cloudflare

2.1 สร้างโปรเจกต์ Proxy

mkdir mcp-proxy
cd mcp-proxy
npm init -y
npm install @modelcontextprotocol/sdk

แก้ไขไฟล์ package.json โดยเพิ่ม "type": "module" ลงไป

2.2 โค้ดสำหรับ mcp-proxy.js

import { SSEClientTransport } from "@modelcontextprotocol/sdk/client/sse.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

// รับ URL จาก Config ของ Claude
const tunnelUrl = process.argv[2] || "https://spectra-qa-test.trycloudflare.com/sse";

async function main() {
  console.error("Starting MCP proxy bridging stdio to:", tunnelUrl);

  // 1. สร้าง Client เชื่อมต่อกับ Remote Server ผ่าน Cloudflare
  const sseClient = new SSEClientTransport(new URL(tunnelUrl));
  await sseClient.start();
  console.error("✅ Connected to remote SSE server.");

  // 2. สร้าง Server รับข้อมูลจาก Claude Desktop ทาง Stdio
  const stdioServer = new StdioServerTransport();
  await stdioServer.start();
  console.error("✅ Stdio transport started for Claude Desktop.");

  // 3. เชื่อมท่อ (Bridge) ส่งข้อมูลไป-มา
  stdioServer.onmessage = (msg) => sseClient.send(msg).catch(console.error);
  sseClient.onmessage = (msg) => stdioServer.send(msg).catch(console.error);

  // 4. จัดการ Connection 
  sseClient.onclose = () => process.exit(0);
  stdioServer.onclose = () => process.exit(0);
}

main().catch(err => {
  console.error("Fatal proxy error:", err);
  process.exit(1);
});

3 ตั้งค่า Claude Desktop

นำ Proxy Script ที่สร้างเสร็จแล้วไปผูกกับ Claude Desktop โดยแก้ไฟล์ claude_desktop_config.json

{
  "mcpServers": {
    "spectra_qa_remote": {
      "command": "node",
      "args": [
        "C:/path/to/your/mcp-proxy/mcp-proxy.js",
        "https://spectra-qa-test.trycloudflare.com/sse"
      ]
    }
  }
}
💡 ข้อสังเกต: อย่าลืมใส่ /sse ต่อท้าย URL ของ Cloudflare ด้วย (ขึ้นอยู่กับการเขียน API ฝั่งเซิร์ฟเวอร์ Machine A ว่าตั้ง Endpoint สำหรับ SSE ไว้ที่ Path ใด)
