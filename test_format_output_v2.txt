        1.1. Fraontend
                             App.js : ไฟล์สำหรับกำหนดเส้นทางของ Routes เพื่อเรียกใช้ Component ที่จะเป็นหน้าเว็บ
                              pages : โฟลเดอร์สำหรับเก็บ Component ที่เป็นหน้าเว็บ ทีถูกเรียกใช้โดย App.js
                            components : โฟลเดอร์สำหรับเก็บ Component ที่เป็นกลาง ที่ถูกเรียกใช้โดย pages
                               configs : โฟลเดอร์สำหรับเก็บการตั้งค่า
                             assets : โฟลเดอร์สำหรับเก็บรูป, ไอคอน และอื่นๆ
                               utils : โฟลเดอร์สำหรับเก็บฟังก์ชันกลาง
                             layouts : โฟลเดอร์สำหรับเก็บ Component ที่เป็นรูปแบบของเว็บ ที่ถูกเรียกใช้โดย App.js
        1.2.      Backend
                              .env : ไฟล์เก็บข้อมูล Config
                           app.js : ไฟล์สำหรับกำหนดเส้นทางของ Routes
                              routes : โฟลเดอร์สำหรับเก็บ Roนtes ที่เป็น APIที่ถูกเรียกใช้โดย app.js
                               controllers : โฟลเดอร์สำหรับเก็บ Controllers ที่เป็นฟังก์ชัน ที่ถูกเรียกใช้โดย routes
                              databases : โฟลเดอร์สำหรับเก็บ JรON ที่เป็น Query ที่ถูกเรียกใช้โดย controllers
                              utils : โฟลเดอร์สำหรับเก็บฟังก์ชันกลาง
