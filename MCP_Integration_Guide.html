คู่มือการเชื่อมต่อ Spectra QA (MCP) เข้ากับ Claude Desktop

เอกสารฉบับนี้อธิบายวิธีการเชื่อมต่อ Spectra QA Server เข้ากับ Claude Desktop อย่างเป็นทางการ ผ่านมาตรฐาน Model Context Protocol (MCP) เพื่อให้ Claude สามารถดึงความสามารถของ Backend ของคุณไปใช้งานได้อัตโนมัติ

1. การตั้งค่าฝั่ง Claude Desktop (Configuration)

เพื่อให้ Claude Desktop รู้จักกับ MCP Server ของ Spectra QA คุณจำเป็นต้องเข้าไปแก้ไขไฟล์ตั้งค่า claude_desktop_config.json

📌 ตำแหน่งของไฟล์ตั้งค่า

  • Windows: %APPDATA%\Claude\claude_desktop_config.json
    (สามารถเปิดผ่าน Run โดยกด Win + R แล้วพิมพ์ค่าดังกล่าว)
  • Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

📌 โค้ดที่ต้องนำไปใส่

ให้คุณเพิ่มโครงสร้าง JSON ด้านล่างนี้เข้าไป (ถ้ามีไฟล์อยู่แล้ว ให้เพิ่มแค่ object spectra-qa-mcp ไว้ใน mcpServers):

{
  "mcpServers": {
    "spectra-qa-mcp": {
      "command": "python",
      "args": ["d:/OCR/backend/mcp_server.py"]
    }
  }
}

หมายเหตุ: หากคุณใช้ Mac ให้เปลี่ยน d:/OCR/backend/mcp_server.py เป็นพาธจริงบนเครื่อง Mac และอาจต้องเปลี่ยน python เป็นพาธเต็มของ Virtual Environment เช่น /path/to/venv/bin/python

เมื่อบันทึกไฟล์เสร็จเรียบร้อย ให้ปิดโปรแกรม Claude Desktop อย่างสมบูรณ์แล้วเปิดขึ้นมาใหม่ (Restart Claude Desktop)

2. เครื่องมือ (Tools) ที่มีให้ใช้งานผ่าน MCP

เมื่อเปิด Claude Desktop ขึ้นมาใหม่ สัญลักษณ์ "ค้อน" (Tools) จะปรากฏขึ้น ซึ่งบ่งบอกว่า Claude เชื่อมต่อกับ Backend สำเร็จแล้ว โดยจะมีเครื่องมือให้ใช้งานทั้งหมด 3 ตัว ดังนี้:

🔍 1. ocr_document (ดึงข้อมูลจากเอกสารรูปภาพ/PDF)
  • หน้าที่: ใช้ดึง Text (Markdown) ออกมาจากไฟล์ PDF หรือรูปภาพ ไม่ว่าจะเป็นไฟล์บนเครื่อง (Local) หรือผ่าน URL (โดยมีการรองรับระบบ SSRF Protection)
  • เมื่อไหร่ที่ Claude จะใช้: เมื่อคุณส่งรูปหรือลิงก์ PDF ให้ Claude และสั่งให้ "อ่านเอกสารนี้ให้หน่อย"
🛡️ 2. evaluate_spectra_qa (ระบบ AI Agent QA Loop)
  • หน้าที่: นำเนื้อหาเอกสาร (Draft) ที่ Claude แต่งเสร็จ ส่งเข้าไปประเมินเทียบกับ Exit Criteria Checklist ของโปรเจกต์คุณ
  • เมื่อไหร่ที่ Claude จะใช้: เมื่อ Claude ร่างเอกสารเสร็จ และต้องการตรวจสอบความถูกต้องว่าผ่านเกณฑ์ของ Spectra QA หรือไม่ หากตกเกณฑ์ ระบบจะบอกจุดผิดพลาด เพื่อให้ Claude นำไปแก้ไขเองอัตโนมัติ (รองรับระบบ Circuit Breaker ป้องกันการติดลูป)
✉️ 3. send_email_report (ระบบส่งอีเมลอัตโนมัติ)
  • หน้าที่: สั่งให้ระบบ Backend ยิงอีเมลพร้อมแนบผลลัพธ์/รายงานไปยังอีเมลปลายทาง
  • เมื่อไหร่ที่ Claude จะใช้: เมื่อเอกสารผ่านเกณฑ์ Exit Criteria แล้ว (APPROVED) Claude จะเรียกเครื่องมือนี้เพื่อทำการส่งอีเมลแจ้งเตือนคุณแบบจบกระบวนการ

3. วิธีการสั่งงานบน Claude (System Prompt & Usage)

หลังจากเชื่อมต่อเสร็จแล้ว สิ่งสำคัญที่จะทำให้ระบบทำงานเป็น "Fully Autonomous" คือการเขียน Prompt ให้ Claude เข้าใจกระบวนการ (Workflow) คุณสามารถใช้ข้อความด้านล่างนี้ เป็น Prompt สั่งงานหรือตั้งเป็น System Prompt (Project Instructions) ได้เลย:

Role:
คุณคือ AI ผู้ช่วยอัจฉริยะ (Spectra QA Agent) ที่มีความสามารถในการอ่านเอกสาร เขียน/แก้ไขเอกสาร และตรวจสอบเกณฑ์คุณภาพ

Workflow (บังคับให้ทำตามลำดับอย่างเคร่งครัด):
  1. หากผู้ใช้แนบลิงก์ไฟล์หรือที่อยู่ไฟล์ ให้คุณใช้ Tool ocr_document เพื่อดึงข้อมูล Text ออกมาก่อน
  2. สรุป/ร่างเอกสารตามคำสั่งของผู้ใช้ (เช่น ร่างเป็นประเภท 'Requirement' หรือ 'Manual')
  3. เมื่อร่างเอกสารเสร็จแล้ว ห้ามเพิ่งส่งให้ผู้ใช้ดู ให้คุณเรียกใช้ Tool evaluate_spectra_qa โดยส่งเนื้อหาทั้งหมด (document_content) เข้าไปตรวจสอบ
  4. หากผลการประเมินแจ้งว่า 'REJECTED' ให้คุณอ่าน failed_criteria ที่ระบบคืนมา แล้วทำการแก้ไขเอกสารให้ถูกต้อง จากนั้นส่งไปประเมินด้วย evaluate_spectra_qa อีกครั้ง (วนลูปจนกว่าจะผ่าน หรือจนกว่าระบบจะแจ้งเตือน Circuit Breaker Hit)
  5. เมื่อได้รับผลการประเมินเป็น 'PASS' ให้คุณใช้ Tool send_email_report เพื่อส่งเนื้อหาที่สมบูรณ์และสรุปผลการผ่านเกณฑ์ไปที่อีเมลที่ผู้ใช้กำหนด
  6. เมื่อเสร็จสิ้นกระบวนการทั้งหมด ค่อยพิมพ์แจ้งผู้ใช้ในช่องแชท พร้อมสรุปผล และพิมพ์เนื้อหาเอกสารฉบับไฟนอลออกมา

💡 สรุปขั้นตอนการทำงาน (The Execution Flow)

หากคุณใช้ Prompt ด้านบน เมื่อคุณทัก Claude ว่า "ช่วยร่าง Requirement สำหรับระบบ Login ให้หน่อย และส่งเมลไปที่ ceo@test.com" สิ่งที่จะเกิดขึ้นคือ:

  • [Drafting] Claude แอบร่าง Requirement ให้คุณเงียบๆ
  • [QA Loop] Claude ส่งที่ร่างไปหา Spectra QA ผ่าน MCP ระบบตีกลับมาว่า "ไม่ผ่านเกณฑ์ข้อ 2 (ข้อมูลสถิติไม่ครบ)" Claude ก็จะแอบแก้ข้อมูลแล้วส่งไปตรวจใหม่
  • [Approved] เมื่อ Spectra QA ตอบกลับว่าสถานะคือ PASS (ผ่านเกณฑ์)
  • [Dispatch] Claude สั่งให้ยิงอีเมลผลลัพธ์ไปที่ ceo@test.com
  • [Finished] Claude ตอบกลับคุณหน้าจอแชทว่า "เรียบร้อยครับ เอกสารผ่านการประเมินและผมส่งอีเมลให้แล้ว นี่คือตัวเอกสารฉบับไฟนอล..."

ทั้งหมดนี้เกิดขึ้นด้วยการพิมพ์คำสั่งเพียงครั้งเดียวของคุณ!
